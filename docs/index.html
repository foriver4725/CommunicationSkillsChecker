Communication Diagnosis

コミュニケーションの苦手ポイント診断

質問に答えるだけで、あなたが会話でつまずきやすいポイントを分析します。
タイミング・思考・緊張・聞く力など、複数の視点から傾向を可視化します。

診断の進め方

  • 全32問・約3分で完了します
  • 4択でテンポよく回答します
  • 深く考えず、直感で選んでください
  • 最後に結果をグラフで表示します

こんな人におすすめ

  • 会話に入るタイミングがわからない
  • 何を話せばいいか迷う
  • 緊張してうまく話せない
  • 雑談が苦手
  • 話したあと反省してしまう

※ 正解・不正解はありません。今のあなたの傾向を見る診断です。
